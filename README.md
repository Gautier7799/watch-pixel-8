# Watch Pixel 8 ⌚✨
### Next-Gen Wear OS 5 & WFF Watch Face Studio

**Watch Pixel 8** هو استوديو ومتجر تفاعلي متقدم لتصميم، معاينة، ومزامنة واجهات الساعات الذكية وفق معيار **Watch Face Format (WFF)** الرسمي المعتمد من Google لـ Wear OS 5 ونظام التصميم **Material You (Material 3 Expressive)**.

---

## 🌟 المميزات الرئيسية (Features)

- ⌚ **محاكي Pixel Watch تفاعلي:** محاكاة حية بحجم 450x450 مع دعم دوران التاج الرقمي باللمس أو بالفأرة وتبديل وضع AOD (Always-On Display).
- 🎨 **محرك Material You Dynamic Theming:** توليد وتطبيق لوحات الألوان التكيفية تلقائياً على واجهة التطبيق وشريط التنقل السفلي.
- 🫀 **محاكي المستشعرات الحيوية (Biometric Sensors):** اختبار وتغيير النبض، عداد الخطوات، ونسبة البطارية لحظياً ومشاهدة تحديث التعقيدات (Complications).
- 📦 **تصدير Watch Face Format (WFF XML):** توليد ملفات `watchface.xml` متوافقة بنسبة 100% مع مواصفات Google Play وWear OS 5.
- 🔄 **مزامنة Wearable Data Layer Hub:** محاكاة طبقة نقل البيانات والاتصال المباشر بين الساعة والهاتف مع سجل تشخيصي لحظي.
- 🌐 **دعم كامل للغتين:** واجهة ثنائية اللغة (العربية والإنجليزية) مع دعم كامل للاتجاه من اليمين لليسار (RTL).

## 🚀 البدء والتشغيل المحلي (Quick Start)

### المتطلبات الأساسية:
- Node.js 18+
- npm أو pnpm أو yarn

### خطوات التثبيت:
```bash
# 1. استنساخ المستودع
git clone https://github.com/your-username/watch-pixel-8.git

# 2. الانتقال لمجلد المشروع
cd watch-pixel-8

# 3. تثبيت الحزم
npm install

# 4. تشغيل خادم التطوير
npm run dev
